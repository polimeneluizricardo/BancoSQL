📚 GUIA DE CONSULTAS SQL — DO BÁSICO AO AVANÇADO

Material de referência com os principais comandos SQL, suas explicações, sintaxes e exemplos práticos.

1. CONSULTAS BÁSICAS
SELECT
sql
SELECT nome
FROM banana;


Explicação:

SELECT: seleciona as colunas que serão consultadas.
nome: coluna que será retornada.
FROM: indica a tabela de origem.

Resultado: retorna todos os valores da coluna nome da tabela banana.

SELECT *
sql
SELECT *
FROM banana;


Explicação:

SELECT: inicia uma consulta.
*: seleciona todas as colunas.
FROM: indica a tabela consultada.
banana: nome da tabela.

Resultado: retorna todas as colunas e todos os registros da tabela banana.

DISTINCT
sql
SELECT DISTINCT cor
FROM banana;


Explicação:

DISTINCT: elimina valores duplicados do resultado.

Resultado: retorna todas as cores existentes na tabela, sem repetir valores.

AS
sql
SELECT nome AS nome_banana
FROM banana;


Explicação:

AS: cria um apelido para uma coluna ou tabela.

Resultado: apresenta a coluna nome com o título nome_banana.

2. FILTROS E CONDIÇÕES
WHERE
sql
SELECT *
FROM banana
WHERE cor = 'amarela';


Explicação:

WHERE: aplica um filtro nos registros.
cor: coluna que será avaliada.
=: operador de igualdade.
'amarela': valor procurado.

Resultado: retorna somente as bananas cuja cor seja amarela.

AND
sql
SELECT *
FROM banana
WHERE cor = 'amarela'
AND tamanho = 'grande';


Explicação:

AND: combina duas ou mais condições.
Todas as condições precisam ser verdadeiras.

Resultado: retorna bananas amarelas e grandes.

OR
sql
SELECT *
FROM banana
WHERE cor = 'amarela'
OR cor = 'verde';
